 # Интернет-магазин (проект с Django)
  ## Описание
  Проект интернет-магазин написан на Django. Проект имеет home и contacts страницы, который будете дорабатывать.
  Подключен PostgreSQL к проекту, создан и настроен модели Product и Category, перенесли их в базу данных с помощью 
  миграций, зарегистрирован и настроить модели в админке, наполнен база данных через Django shell, создан фикстуры для
  моделей и реализовать кастомную команду для добавления тестовых данных.

  ## Скриншоты
  Через инструмент shell заполните список категорий, а также выберите список категорий, применив произвольные 
  рассмотренные фильтры. Скриншоты находятся в пакет catalog/media/screenshots

    *В Django shell создан несколько категорий и продуктов.
    *Выполнен следующие запросы:
        -Получите все категории.
        -Получите все продукты.
        -Найдите все продукты в определенной категории.
        -Обновите цену для определенного продукта.
        -Удалите продукт.
  
   ## Продукти
    1 Создан класс формы для продукта.
    2 Реализованы CRUD-операции для продуктов с помощью форм.
    3 Собраны шаблоны с использованием форм.
    4 Форма подключена в соответствующие контроллеры работы с продуктом.
    5 В форме отображены все поля для создания/обновления объекта продукта.
    6 Собран шаблон для подтверждения удаления продукта.

  ## Валидация
    1 Реализована валидация на запрещенные слова отдельно для имени и отдельно для описания.Список запрещенных слов
      хранится в константах и переиспользуется в методах.
    2 Валидация проходит с помощью методов clean_... , clean для полей формы.
    3 Добавлена кастомная валидация для поля price. Валидация проверяет, что цена продукта не может быть отрицательной.
         Если цена введена неправильно, отображается соответствующее сообщение пользователю в ошибке ValidationError.
